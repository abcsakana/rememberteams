# ⚾ アメスポ州マスター 🏈

MLB(メジャーリーグ)全30チームと NFL(アメフト)全32チームの本拠地の州を、
楽しく覚えるための学習アプリです。インストール不要・ブラウザだけで動きます。

## 機能

- **🗺️ マップ** — タイル式のアメリカ地図。州ごとのチーム数が色で分かり、タップするとその州のチーム一覧が見られます(チームがない州も分かる!)
- **📚 学習** — 州ごとのチーム一覧。MLB/NFLの絞り込みと、チーム名・州名での検索ができます
- **🎯 クイズ** — 「チーム→州」「州→チーム」の4択クイズ(10問1セット)。連続正解で🔥、正解すると豆知識も表示
- **🏆 成績** — 同じチームに3回正解すると「マスター(🏆)」。62チーム制覇を目指そう!記録はブラウザに自動保存されます

## iPhoneでの使い方

### 一番かんたん: GitHub Pages で公開する

1. このブランチを `main` にマージする(またはそのままこのブランチを使う)
2. GitHubのリポジトリページで **Settings → Pages** を開く
3. 「Source」で **Deploy from a branch** を選び、ブランチと `/ (root)` を指定して保存
4. 表示されたURL(`https://<ユーザー名>.github.io/<リポジトリ名>/`)をiPhoneのSafariで開く
5. 共有ボタン → **「ホーム画面に追加」** で、アプリのように使えます📱

### ローカルで試す場合

`index.html` をブラウザで開くだけでも動きます(全データ内蔵・通信不要)。

## メモ

- ニューヨーク・ジャイアンツ/ジェッツのスタジアムは実はニュージャージー州、
  ワシントン・コマンダースのスタジアムはメリーランド州にありますが、
  クイズでは慣例どおりの本拠地(NY / D.C.)を正解としています(豆知識として表示されます)
- トロント・ブルージェイズはカナダのチームなので「番外編」扱いです
- アスレチックスは2025年からサクラメント暫定本拠地(ラスベガス移転予定)としています
